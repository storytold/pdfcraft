# PdfCraft for Android

A reader: open a PDF, view its pages, page through it, pinch to zoom, find text and jump through
the outline. No editing yet — that's `pdfcraft-engine`'s surface, out of scope for this crate
until a later milestone (see `crates/mobile-ffi/src/lib.rs`).

The Kotlin UI never touches the PDF directly; it calls `MobileDocument` (generated by UniFFI from
`crates/mobile-ffi`) for everything PDF-related.

## Build

1. Install an Android NDK and point `$ANDROID_NDK_HOME` at it, and `cargo install cargo-ndk`.
2. From the repo root: `cargo xtask mobile android`. This cross-compiles `pdfcraft-mobile-ffi` for
   `arm64-v8a`/`armeabi-v7a`/`x86_64` into `app/src/main/jniLibs/`, and generates the Kotlin
   bindings into `app/src/main/java/uniffi/pdfcraft_mobile_ffi/`. Both are git-ignored and must be
   regenerated after any change to `crates/mobile-ffi/src/lib.rs`.
3. Open this directory in Android Studio, or `./gradlew assembleDebug` / `./gradlew installDebug`
   with an emulator or device running.

Nothing here has been built or run yet — this scaffold hasn't seen an Android SDK/NDK or an
emulator. `./gradlew wrapper` was run to generate a real wrapper; the Kotlin/Gradle-DSL files
themselves parsed cleanly under Gradle 8.14.3, but plugin resolution (needs `dl.google.com`) and
everything past it is unverified.
