Open a file with **File**, **Open…** (`Ctrl+O`), then use the **View** menu for layout and zoom and `Ctrl+F` to search.

Shortcuts on this page use Ctrl. On macOS, use Cmd instead of Ctrl.

## Open a file

1. Click the **Menu** button, then **File**, then **Open…**. Or press `Ctrl+O`.
2. Choose the PDF. To open several at once, select them all in the dialog.

You can also drop a PDF on the window, or click a file under **Recent** on the home screen. If the file is protected, PdfCraft asks for the password: "Password required", then **Open**.

Several files can be open at once, each in its own tab.

## Change how pages are shown

Open **Menu**, **View**. The page display options are:

- **Single page** or **Two-page view**
- **Continuous scrolling**, as a checkbox
- **Show cover page in two-page view**
- **Read mode**, a distraction-free layout for long reading
- **Full screen mode** (`Ctrl+L`)

The zoom items are **Actual size**, **Zoom to page level**, **Fit to width**, **Fit to height**, **Fit visible**, **Zoom in** and **Zoom out**. `Ctrl+1` is actual size, `Ctrl+0` fits the page and `Ctrl+2` fits the width. Use **Go to page…** to jump to a page.

**Display theme** in the same menu offers **Use system setting**, **Light gray** and **Dark gray**.

## Search for text

1. Press `Ctrl+F`, or choose **Edit**, then **Find…**.
2. Type a word or phrase. PdfCraft searches as you type and shows "1 of 16" style counts.
3. Press `Ctrl+G` for the next match and `Ctrl+Shift+G` for the previous one.
4. Open **Find options** to turn on **Whole words only** or **Case-sensitive**.
5. Press `Esc` to close the find bar.

To search across the whole document in a panel, choose **Edit**, then **Advanced search…**.

## Find a tool or command

Press `Ctrl+K` to open the command palette and type a name, such as "rotate". The palette searches every tool and command.
