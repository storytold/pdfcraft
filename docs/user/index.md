PdfCraft is a free, open-source app for working with PDF files. You read them, rearrange their pages, combine and split them, comment on them, fill in forms and protect them with a password. It is an alternative to Adobe Acrobat.

It runs on your computer. There is no account, no telemetry and no cloud processing. PdfCraft is in alpha: everyday work is possible, but some Acrobat features are still missing. See [Can PdfCraft replace Adobe Acrobat?](faq/replace-acrobat.md).
