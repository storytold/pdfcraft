# Git & GitHub Collaboration Resources

## Knowledge

- [Pro Git Book by Scott Chacon and Ben Straub (Official & Free)](https://git-scm.com/book/en/v2)
  The definitive primary source on Git. Use chapters 2 (Git Basics), 3 (Git Branching), and 5 (Distributed Git) for deep foundational understanding of remotes, merges, and rebasing.
- [GitHub Docs: Working with forks](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/working-with-forks)
  Official guide explaining the relationship between an upstream repository and personal forks, and configuring remote URLs.
- [GitHub Docs: Syncing a fork branch](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/working-with-forks/syncing-a-fork)
  Step-by-step procedures to fetch upstream branches and merge them into a local branch or web fork.
- [GitHub Docs: Resolving a merge conflict using the command line](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/addressing-merge-conflicts/resolving-a-merge-conflict-using-the-command-line)
  Concise reference for spotting conflict markers (`<<<<<<<`, `=======`, `>>>>>>>`) and finalizing the merge commit.

## Wisdom (Communities)

- [GitHub Community Discussions](https://github.com/orgs/community/discussions)
  Active community of open-source contributors and maintainers discussing PR workflows, permissions, and GitHub Actions.
- [Stack Overflow: [git] Tag](https://stackoverflow.com/questions/tagged/git)
  The highest-density repository of real-world edge cases, detached HEAD recovery, and complex conflict resolutions.
