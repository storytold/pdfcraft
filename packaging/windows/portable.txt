Linkco PDF Editor portable mode

While this file sits next to LinkcoPDFEditor.exe or pdfcraft.exe, Linkco PDF Editor keeps its
settings, log files, crash-recovery autosaves and new digital IDs in the PdfCraftData folder
beside it, and writes nothing to %APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move
Linkco PDF Editor with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\Linkco PDF Editor and
%LOCALAPPDATA%\Linkco PDF Editor) instead. If PdfCraftData can't be written (for example on a
read-only drive), Linkco PDF Editor says so and uses the per-user folders instead.
